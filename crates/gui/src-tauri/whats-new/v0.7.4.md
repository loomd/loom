## **1. 新增 MiniMax Code (mcode) 运行状态与灯态监听**
Loom 现已全面支持对 MiniMax Code (mcode) 运行状态的只读实时监控，精准捕获 Running（运行中）、Waiting（就绪等待）、Question（问卷提问/等待确认）以及 AgentCall（子 Agent 派发）等多维度的细分状态。

## **2. 终端 Shell 区域 Tab 栏灯态无缝呈现**
在工作区 Shell 区域及多终端 Tab 栏上新增 mcode 呼吸灯态动效，无论单终端还是多窗分屏，各终端内 Agent 的工作状态一目了然。

## **3. 支持 mcode 基于 Session ID 的精准自动恢复**
重启应用或重新切换项目时，Loom 会自动记忆当前终端绑定的 mcode 会话 ID，并通过 `mcode --session <id>` 自动恢复历史会话，确保交互上下文不中断。
